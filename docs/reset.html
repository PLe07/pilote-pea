Réparation

Un ancien service worker installé par une autre application du même domaine peut intercepter les fichiers de Pilote PEA et empêcher son chargement. Cette page fait le ménage.

État actuel

analyse en cours…

Nettoyer

Désinscrit tous les service workers de ce domaine et vide tous les caches. Aucune de tes données personnelles n'est touchée : montants, profil et convictions vivent dans le stockage local, pas dans les caches.

Retour à l'app

Si ça ne suffit pas

1. Le test qui tranche en dix secondes

Ouvre l'app dans une fenêtre privée (Cmd+Maj+N sur Safari). Les service workers n'y tournent pas. Si l'app s'affiche correctement en privé, le coupable était bien un service worker — et cette page l'a réglé pour la navigation normale.

2. Vider le cache de Safari

Menu Développement → Vider les caches, puis Cmd+R. Si le menu Développement est absent : Réglages → Avancées → « Afficher les fonctionnalités pour développeurs web ».

3. Vérifier que les fichiers sont bien en ligne

Ouvre directement styles.css et app.js. Si l'une des deux affiche une page « 404 », le dossier n'a pas été poussé en entier : relance Installer.command.
